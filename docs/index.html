What's inside

Everything you need to analyse a CAN bus

No account, no server, no subscription. Everything runs on your machine.

📡

Live Frame Monitor

Real-time scrolling table with 500-row circular buffer. Pause, clear, and filter on the fly. Hardware timestamps via io_uring.

📄

DBC Signal Decoding

Load a .dbc file and decoded signal values appear inline in the frame table. Full round-trip lossless parser — VERSION, BU_, BO_, SG_, VAL_, CM_.

📈

Signal Graphs

Up to 4 live traces on a rolling 10-second QChart window. Watch voltages, temperatures and speeds in real time.

📤

Frame Transmit

Send standard, extended or FD frames with input validation. Perfect for testing ECU responses.

🔌

Interface Auto-detect

Scans /sys/class/net for all ARPHRD_CAN interfaces. Hot-swap adapters without restarting the app.

🧩

Protocol Decoders

Built-in stateless decoders for CANopen NMT/SDO/PDO/EMCY, J1939, ISO-TP, UDS, OBD-II and NMEA 2000.

🌙

Lua 5.4 Scripting

Automate bus interactions with a sandboxed Lua engine. Watchdog thread prevents runaway scripts. CAN, SDO and log APIs built in.

🤖

Claude MCP Integration

JSON-RPC 2.0 server (stdio or TCP on 127.0.0.1) exposing 11 tools to Claude Desktop and Claude Code. Ask Claude to decode frames, send commands, or run scripts.

⚡

io_uring Capture

High-throughput frame capture pipeline with hardware timestamps and a lock-free SPSC ring buffer — no frames dropped at high bus loads.
